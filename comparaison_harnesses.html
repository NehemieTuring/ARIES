ARIES — comparaison inter-harness

Trois harnesses, deux tâches

OpenClaw, Hermes et Claude Code lancés sur les mêmes tâches Terminal-Bench 2 dans ARIES — même sandbox, la même télémétrie CPU/mémoire échantillonnée chaque seconde.

30 runs réels · n=5 par harness et par tâche · 17 août – 5 sept. 2026 · pont SSH révoqué avant chaque évaluation

⚠️ Modèles différents, pas seulement les harnesses : OpenClaw et Hermes tournent sur DeepSeek (même modèle — leurs écarts sont donc imputables au harness), Claude Code sur Claude Sonnet 5. Tout écart impliquant Claude Code mélange encore l'effet du harness et celui du modèle. Un protocole à modèle constant (même modèle pour les trois, via ANTHROPIC_BASE_URL) reste nécessaire pour isoler complètement l'effet du harness.

Méthodologie et limites
  • Modèles différents : OpenClaw/Hermes sur DeepSeek, Claude Code sur Claude Sonnet 5 — voir l'avertissement en haut de page. Les comparaisons impliquant Claude Code n'isolent pas l'effet du harness seul ; la comparaison OpenClaw/Hermes, elle, est à modèle constant.
  • Métriques du composant harness uniquement (le conteneur agent, pas le sandbox de la tâche) — c'est l'empreinte propre à chaque harness, indépendante de la tâche elle-même.
  • « Pic CPU » = valeur maximale de cpu_percent sur la durée du run (peut dépasser 100% : plusieurs cœurs). « Mémoire moyenne » = moyenne de memory_usage_bytes sur tous les échantillons.
  • n=5 par harness et par tâche (30 runs au total) : après une première observation à n=1-5, chaque harness a été relancé jusqu'à atteindre 5 tentatives réelles sur chacune des deux tâches, aucun résultat écarté ni relancé pour améliorer un chiffre. Le survol d'un point donne la date/le numéro exact du run ; le trait marque la moyenne par harness.
  • OpenClaw ne réussit overfull-hbox-001 que 2 fois sur 5 (contre 5/5 pour Hermes, même modèle, et 4/5 pour Claude Code) — un écart de fiabilité mesuré sans confusion de modèle, pas encore diagnostiqué. Sur fix-git-001 : 4/5 pour OpenClaw et Claude Code, 5/5 pour Hermes ; les échecs observés sont soit un résultat incorrect, soit — pour Claude Code — une question de clarification plutôt qu'une tentative face à un conflit de fusion réellement ambigu.
  • Échantillon encore modeste (n=5) : à cette taille, seuls les écarts nettement supérieurs à l'écart-type entre runs d'un même harness sont interprétables — un écart plus fin resterait indiscernable du bruit.
